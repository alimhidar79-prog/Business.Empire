# Business Empire — Android

## النشر من الهاتف فقط
1. أنشئ مستودع GitHub جديد باسم Business-Empire.
2. ارفع كل محتويات هذا المجلد إلى المستودع، مع الحفاظ على مجلد `.github/workflows`.
3. افتح تبويب Actions.
4. اختر **Build Business Empire APK**.
5. اضغط **Run workflow**.
6. انتظر حتى تنتهي العملية.
7. افتح نتيجة العملية وستجد **Artifacts → Business-Empire-APK**.
8. نزّل ملف ZIP، فك ضغطه، ثم ثبّت ملف APK على هاتف Android.

## ملاحظة
هذا يبني Debug APK للتجربة. قبل Google Play نحتاج لاحقًا إعداد نسخة Release موقعة.
